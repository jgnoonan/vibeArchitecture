# Examples

Concrete illustrations of vibeArchitecture in use — start here if you want to see what changes after install.

| File | What it shows |
|------|---------------|
| [first-success-walkthrough.md](first-success-walkthrough.md) | End-to-end first session: prompt → intake → profile → first feature |
| [sample-PROJECT_PROFILE.md](sample-PROJECT_PROFILE.md) | A completed profile after intake (Recipe Box app, Shared tier) |
| [before-and-after.md](before-and-after.md) | Same login API request — naive AI output vs vibeArchitecture-guided output |

The walkthrough uses the Option B prompt (the raw `BOOTSTRAP.md` URL from GitHub) and shows the full 1.5.0 intake, including the two questions added in this release — how people will use the app (**platform**) and what happens if it goes down (**downtime impact**). The sample profile records both.

These are documentation only. They are not runnable projects.
